# Navya Shah – AI & Data Science Portfolio

A personal portfolio website showcasing my skills, projects, education,
experience and contact information.

## Technologies Used
- **HTML5** – semantic markup (header, nav, section, footer)
- **CSS3** – custom properties, flexbox, grid, media queries, hover effects
- **JavaScript (ES6)** – mobile menu, dark/light mode toggle, form validation

## Features
- Responsive layout (mobile + laptop)
- Dark / Light mode toggle (saved in localStorage)
- Mobile hamburger menu
- Contact form with client-side validation
- Smooth scrolling and hover animations
